How to play
Controls

Put Sunset Racer 4P on all 4 dials, dial n = player Pn.
Press dial: join (race starts 10 s after the first join, or when everyone joined)
Tap strip: start now / pause / resume
Rotate dial: steer
Press dial: boost, 3 per race (gas is automatic)
Long press strip: back to lobby
Steering is per player. Race Length and Traffic are shared, the last change wins.
Add "Racer Map" on the keys above for a live map.
